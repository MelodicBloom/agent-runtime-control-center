# 09 — Daily Automation

## Daily 8 AM — Chief of Staff Brief

Returns top 3 priorities, stale projects, blocked tasks, opportunities, one money move, one creative move, one maintenance move.

## Daily 9 AM — Repo Health Scan

Checks main branch build status, open PRs, failed GitHub Actions, stale issues, missing README, missing deployment.

## Daily 11 AM — Funding Scan

Finds grants, accelerators, residencies, client leads, creative technology calls, and AI/design funding opportunities. Must use fresh search.

## Daily 4 PM — Packaging Progress

Checks Gumroad readiness, README readiness, asset completeness, demo deployment, screenshots, and pricing copy.

## Weekly Monday — Architecture Review

Compares all projects for shared components, duplicated systems, repo consolidation opportunities, missing docs, reusable packages.

## Weekly Friday — Release Candidate Review

Finds what can ship, what should not ship, what needs one PR, sales page, or visuals.
